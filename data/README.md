# Dữ liệu xe điện Washington

Thư mục này lưu dữ liệu phục vụ phân tích đặc điểm, phân bố và dự báo quy mô đội xe điện tại bang Washington. Các file CSV raw và clean được chia sẻ qua Google Drive:

| Nhóm dữ liệu | Nội dung | Link tải |
|---|---|---|
| Raw | Hai bộ dữ liệu gốc Population và History, trước khi tiền xử lý | [Dữ liệu raw trên Google Drive](https://drive.google.com/drive/folders/1Bp67CYHvmcQcsPUAWl13ZHT_P1s3bWib?usp=sharing) |
| Clean | Hai bộ dữ liệu Population và History sau tiền xử lý, chỉ giữ phạm vi Washington (`State = WA`) | [Dữ liệu clean trên Google Drive](https://drive.google.com/drive/folders/1YvG-HDCbabV6dt6lo1BkaxUJd-wX4qTq?usp=sharing) |

Quy trình tiền xử lý và hướng dẫn chạy Python được trình bày tại [source/preprocessing](../source/preprocessing/README.md).
